# Harbor

Progressive web app for postpartum depression and postpartum psychosis — help, prevention, and a clear split between the two.

Visual template recreates [theothertd.com](https://www.theothertd.com/) campaign chrome (Phase 1 at `/plate`), then pours Harbor content into that system (Phase 2 at `/`).

Not a diagnostic tool. Not affiliated with Postpartum Support International, Teva Neuroscience, CBS, or any hospital system.

## Live routes

- `/` Harbor home
- `/help` crisis numbers
- `/learn/ppd` postpartum depression
- `/learn/ppp` postpartum psychosis
- `/learn/difference` side by side
- `/check-in` private education screen
- `/partners` caregivers
- `/prevention` plan before birth
- `/resources` real doors
- `/about`
- `/plate` exact-site template recreation

## Crisis numbers

- 911 if anyone is in immediate danger
- 988 Suicide & Crisis Lifeline
- National Maternal Mental Health Hotline: 1-833-852-6262
- PSI HelpLine: 1-800-944-4773 (not emergency care; 8am–11pm ET)
